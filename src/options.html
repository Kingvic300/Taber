Tabora settings

Changes save on their own.

Duplicate tabs

When you open a page that is already open, Tabora keeps one tab and closes the copy. http/https, www. and a trailing / count as the same page.

Join tabs into groups

Puts related tabs into one tab group. Topics come first (Dev, Video, …); other tabs are grouped by site.

tabs

This browser has no tab groups. Tabora puts related tabs next to each other instead.

Sleep idle tabs

A sleeping tab stays in the tab bar but uses no memory or CPU. Click it and it loads again.

CPU-heavy tabs

Tabora watches how busy each background page keeps the browser. A page that stays busy too long is put to sleep. The tab you are on and tabs playing sound are left alone.

Tabora needs access to websites to watch CPU use.

seconds

Browsers do not give extensions exact CPU numbers, so this is an estimate of the page's main work. Heavy work in background threads (Web Workers) is not seen.

Smart keep

Tabora learns which sites and tabs you use most. It never closes those tabs on its own: the tab limit, old-tab cleanup and CPU cleanup put them to sleep instead, and they stay awake twice as long. Use fades after about a week, so sites you stop using drop off the list.

Tab limit

Keeps each window under a set number of tabs by acting on the least recently used ones.

Close old tabs

Closes tabs you have not looked at for a long time. Pinned tabs, the tab you are on and tabs playing sound stay open. Restore closed tabs from the popup.
